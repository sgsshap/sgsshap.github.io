# 项目术语（JxShap / diy-card）

维护本仓库 **用户可见文案、中文注释、文档** 与 **代码命名** 的用词一致性。

## 何时使用

在以下场景 **先读** [glossary.md](glossary.md)，再动手：

- 写/改中文注释、UI 文案、错误提示、历史记录文案
- 新建 composable、store、类型、图层 code 的命名与说明
- 与用户讨论功能（回复也用术语表里的叫法）
- 重构时判断旧名是否应保留为代码符号

## 执行规则

1. **用户向 vs 代码向**：术语表区分两列；用户可见处用「推荐叫法」。
2. **画布 ≠ 舞台**：面向用户或中文注释一律说 **画布**。
3. **用户文案禁技术库名**：界面提示、tooltip、设置说明等 **禁止出现 Konva、Stage、vue-konva** 等实现细节；卡面相关说 **卡牌 / 卡面 / 画布**，站点 UI 说 **界面 / 网站**。
4. **不臆造同义词**：未收录且含义不确定时，**先问用户**，确认后写入 `glossary.md`。
5. **同轮合并**：同一词条/主题合并一条变更记录。
6. **牌种优先于模板**：先说武将牌/游戏牌/标记牌，再说具体模板名。
7. **与 vue3-standards 并存**：工程结构遵循 `vue3-standards`；本 skill 只管领域用词。
