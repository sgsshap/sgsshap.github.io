## 2. 画布与版面（核心）


| 推荐叫法        | 代码 / 英文标识                                         | 说明                                              | 避免使用                                       |
| --------------- | ------------------------------------------------------- | ------------------------------------------------- | ---------------------------------------------- |
| **画布**        | `DiyPreview` 预览区、用户口中的「制图区域」             | 用户在制图页看到并操作的卡面预览区域              | **舞台**、Stage（中文注释/UI 中）              |
| **Konva Stage** | `Konva.Stage`、`stageRef`、`getStage()`                 | Konva 库的根容器；**仅技术语境**使用              | 严禁使用「舞台」这个中文词汇                   |
| **成品区**      | `trim`、`stageConfig` 宽高、`resolveStageContentBounds` | 不含出血的实际卡牌印刷区域；预览中红色虚线框内    | 内容区（单独用时易歧义）                       |
| **出血**        | `bleed`、`bleedFlag`、`bleedValue`                      | 印刷裁切预留边；可开关、可调宽度（mm）            | 边距                                           |
| **含出血画布**  | `finalStageConfig`                                      | Konva Stage 逻辑尺寸 = 成品区 + 两侧出血          | —                                             |
| **画布内容区**  | `resolveStageContentBounds`、`stageOrigin` 内区域       | 布局 mm 坐标的参照区域（通常等同成品区）          | —                                             |
| **成品区原点**  | `stageOrigin`、`contentOrigin`、`innerStageBleed`       | 成品区左上角在 Stage 坐标系中的偏移（px）         | —                                             |
| **mm 坐标**     | `LayoutItem.x/y`、`mmToPx`                              | 布局数据以 mm 存于`renderConfig`；上屏时换算为 px | —                                             |
| **圆角白边**    | `whiteBorder`                                           | 导出时成品外侧 3mm 白边（与出血互斥）             | —                                             |
| **固定画布**    | `useDiyCanvasPin`、`isPinned`                           | PC 滚动页面时画布区域`position: fixed` 保持可见   | 吸顶画布（易与贴边吸附混淆）                   |
| **悬挂预览**    | `useDiyCanvasFloatPreview`                              | 主画布滚出视口后，屏幕边缘的紧凑浮动预览          | 小窗预览、悬浮窗（口语可接受，文档用悬挂预览） |
| **贴边 / 吸附** | `snapToStageEdge`、`resolveCanvasEdgeBoundsFromDiy`     | 拖拽图层时自动对齐**画布边缘**（`finalStageConfig` 外缘）并显示参考线 | 成品区边缘、吸顶（仅指贴齐顶部边时口语可说「贴顶」） |

## 4. 模板类型、模板与数据模型

| **保存进度 / 读取进度** | `DiyExportBar`                                   | 导出/导入`.shap`                                | 保存项目                         |
| **撤销 / 重做**         | `useDiyHistoryStore`                             | 本地操作历史栈                                  | —                               |
| **落库**                | 拖拽结束写回`renderConfig`                       | 把画布上的位置/尺寸写回 mm 数据并持久化         | 保存到数据库                     |

## 7. 操作与工程行为


| 推荐叫法     | 代码                                    | 说明                               | 避免使用                 |
| ------------ | --------------------------------------- | ---------------------------------- | ------------------------ |
| **重载**     | `reloadMaterial`、`runWithLoading`      | 按图层重新`load` 并刷新 Konva 节点 | 刷新页面                 |
| **选中**     | `selectedItem`、`useKonvaNodeSelection` | 点选画布上可编辑图层               | 激活                     |
| **导出**     | `useExportStore`、导出 PNG              | 生成印刷用图片文件                 | 下载（进度文件除外）     |
| **预览**     | 画布实时渲染                            | 区别于导出成品图                   | —                       |
| **智能抠图** | `matting`、`autoMatting`                | 出框编辑器内 AI 抠图               | 抠图（语境明确时可简称） |
| **蒙版**     | `maskCanvas`、出框蒙版                  | 控制出框区域透明度的灰度图         | 遮罩（DOM 语境外）       |

## 8. 代码命名约定（术语相关）


| 场景           | 约定                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------ |
| 用户可见字符串 | 用本节「推荐叫法」；**禁止** Konva / Stage / vue-konva 等库名                         |
| 中文注释       | 用推荐叫法；必要时括号注明 code（如`武将图（legendImage）`）                           |
| 变量/文件      | 可保留`stage`、`trim`、`legend` 等历史英文名，但新增模块优先 `canvas` / `trim` / `legend` 等与现有一致 |
| Konva 专有     | `Stage`、`Layer`、`Node` 仅代码与内部文档；**不得**出现在用户可见文案                    |
| 坐标           | `originX/Y` = 布局包围盒左上角；`stageOrigin` = 成品区原点在 Stage 上的偏移                            |
